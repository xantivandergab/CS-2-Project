# Budgify
## Project Description
Budgify is a percentage-based budget tracking program that allows users to allocate their total budget into different spending categories. Users can input their expenses, and the program automatically computes the amount of money that has been used up, and how much remains. This program helps users monitor their spending habits and stay within their budget plan
## Features
- Split budget into different categories
- Automatic calculation of budget use
- Reminder if user goes over budget
- Adjustable budget allocation ratios
- Activity history to check previous expenses
## How to run the program

## Inputs needed
- Budget of user
- Categories for rations
- Percentages for each category
- Expense of user for each category
- Option to change rations for each category
- Option to remove a category
- Option to change input expense
